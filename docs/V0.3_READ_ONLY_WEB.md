# V0.3 — Luna Native Read-Only Web Search

SENTRY uses Luna/Codex's native live web-search capability for an explicitly
requested public lookup. The production path is:

```text
user request
→ Luna planner selects use_native_web_search
→ host validates the typed authorization marker
→ one ephemeral Luna synthesis turn with Codex CLI --search
→ native web search / source reading
→ sourced grounded reply
```

The SENTRY host does not implement a second search engine, scrape result pages,
or make direct public HTTP requests. `use_native_web_search` is a typed
authorization marker only: it performs no network operation itself. The
synthesis bridge adds Codex CLI's global `--search` option only for that
request-scoped, planner-authorized synthesis turn.

## Scope

Luna may use native web search for public, read-only research, including a
user-named place/date weather lookup or a public URL the user asks it to read.
Normal SENTRY-local requests remain local and do not enable web search.

Native web search is read-only. It is not authorization for login, form
submission, uploads, purchases, posting, account changes, private-network
access, shell use, filesystem access, or other external writes.

## Local-data and privacy boundary

- The planner and synthesis prompts prohibit sending SENTRY-private identity,
  room history, reminder text, home coordinates, secrets, or local tool output
  into a web query.
- The configured private home-weather cache remains `get_weather`; it does not
  disclose the private coordinate configuration to the native web tool.
- Public web research is request-scoped. SENTRY does not persist web extracts,
  web-search transcripts, embeddings, or a web archive.
- SENTRY-local claims still require normal typed local facts and fact-ID
  validation. The `web:native-search-authorized` fact records authorization,
  not a claim that any individual web source is true. Native web sources are
  cited naturally in the response itself.

## Operational behavior

The bridge uses the existing OAuth-authenticated Codex CLI with `--ephemeral`,
`--json`, `--ignore-user-config`, `--skip-git-repo-check`, read-only sandbox,
and `--search`. No API key, host web client, added provider account, or custom
search credential is required.

The local NWS timer remains useful for private home weather and proactive
context. Native web search is the public research path, not a replacement for
SENTRY's private local context or physical grounding.
