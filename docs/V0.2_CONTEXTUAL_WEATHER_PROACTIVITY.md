# V0.2 contextual weather proactivity

This feature extends the existing M5 `person.identified` candidate with one
bounded contextual gate. It does not add departure detection, outdoor-intent
inference, a new event class, or weather-alert speech.

## Gate

The existing physical and policy gates run first: enabled event, primary user,
fresh event, restart provenance, occupied current session, healthy source,
startup stabilization, explicit acknowledgement preference, same-session
dedupe, cooldown, hourly budget, and speech-busy state. Only a candidate that
survives those gates reads weather context.

The processor reads the local schema-7 weather snapshot only. It never calls
NWS. The event timestamp through the next 120 minutes is examined. A forecast
period must overlap that interval and provide a numeric precipitation
probability of at least 60 percent. Missing usable probability is
`weather_insufficient`; no overlapping period or a lower maximum probability
is `weather_not_relevant`.

## Outcomes

The contextual suppressions are persisted in the existing `proactive_actions`
record:

- `weather_unconfigured`
- `weather_unavailable`
- `weather_stale`
- `weather_insufficient`
- `weather_not_relevant`

All are deterministic and invoke zero Luna turns. A relevant candidate adds
only `weather-context-health` and `weather-near-term-precipitation` to the
existing bounded proactive fact packet. Coordinates, provider URLs, raw NWS
payloads, alerts, routines, and biometric data are not supplied.

Luna remains an optional single low-effort judgment after every deterministic
gate. It may choose `speak` or `silent`; any speech remains limited to 20 words
and 160 characters. The prompt forbids inferring departure, destination,
commuting, outdoor plans, or emergency meaning.

## Production boundary

The production configuration currently has no explicit weather section or
coordinates. No production weather rows were seeded. A valid production
candidate therefore receives `weather_unconfigured` and makes zero Luna calls.
The weather timer and contextual path are not enabled automatically.

Qualification used a public NWS coordinate only for transport proof. The real
snapshot had a fresh 32 percent maximum precipitation probability within the
120-minute horizon and correctly suppressed as not relevant. A separate
metadata-only normalized fixture at 80 percent proved one bounded speech
decision and replay dedupe.
