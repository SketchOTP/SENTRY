# Task Packet — SENTRY-OPERATOR-CODEX-NATIVE-AGENT-001

## Objective

Make the installed OAuth-authenticated Codex CLI the direct natural-language
agent runtime for SENTRY. Expose trusted SENTRY office context, on-demand local
vision, and desktop operations as typed MCP tools while retaining Codex-native
web, shell/file, browser, skill/plugin, and image-generation capabilities.

## Scope

- Replace the planner -> host-tool -> synthesis split for operator conversation
  with one Codex agent turn that can select and call tools directly.
- Add a dedicated SENTRY Codex profile, skill, and local stdio MCP server.
- Reuse accepted office state/history/reminder/preference/routine/weather logic.
- Add bounded on-demand camera inspection using the enrolled local identity
  profile, without persisting frames.
- Add Linux desktop tools for application discovery/launch, PipeWire volume,
  and media control where the host exposes a supported local interface.
- Enable Codex workspace code/file changes and its native public web and image
  generation capabilities for explicit operator requests.
- Preserve Vosk, Whisper, Kokoro, current physical truthfulness, identity
  conservatism, privacy, and the one-office-room product boundary.

## Operator override

The operator explicitly authorizes local code/file changes, local computer
control, native public internet research, image generation, and tool use from
natural-language SENTRY requests. Codex remains responsible for interpreting
the requested action, using the smallest suitable tool, and refusing to invent
success or physical facts.

## Exclusions

No cloud video upload, ambient transcript archive, biometric weakening,
multi-room expansion, new sensor, schema migration unless proven necessary,
or replacement of Vosk/Whisper/Kokoro/perception models merely to expose tools.

## Stop conditions

Return to the Architect if the installed noninteractive CLI cannot load the
required MCP/skill/image surfaces, on-demand vision cannot share the existing
camera safely, direct agent execution breaks accepted grounding or identity
truthfulness, or Linux desktop control requires unsupported graphical Computer
Use rather than reproducible local interfaces.
