# SENTRY-V0.2-RESIDENT-RUNTIME-001

## Objective

Run the accepted V0.1 office stack continuously under native Ubuntu user-systemd supervision so it can accumulate longitudinal metadata history without routine manual launching.

## Scope

- Add bounded continuous mode to the existing proactive processor.
- Install separate user services for perception, the localhost state API, and proactive processing.
- Create a local ignored production configuration from the checked-in example without changing detector, identity, persistence, voice, or M4/M5 policy behavior.
- Prove bounded restart/isolation behavior, startup enablement, live FPS/health, and clean stop.

## Exclusions

No routine learning, new sensors/rooms, detector or tracker changes, new proactive event classes, continuous microphone listening, database replacement, or whole-home work.

## Acceptance

The services are enabled for the configured user startup condition, restart with bounded backoff, remain isolated, preserve the local-SQLite/Atlas-mirror topology and one-open-session invariant, and pass focused plus full regression validation and a supervised live window.
