# Task Packet — SENTRY-OPERATOR-JARVIS-EXECUTION-001

## Objective

Make SENTRY the operator-facing, wake-activated resident persona while one
direct Codex CLI turn acts as its general natural-language execution brain.
Compound requests must execute in the operator's stated order and may compose
Codex-native web, image, shell/file, skill/plugin, and local SENTRY MCP tools.

## Operator override

The operator explicitly authorizes natural-language local code/file work,
desktop control, public web research, image generation/display, and other
available Codex capabilities. The wake token remains exactly `Sentry`.

## Scope

- Strengthen the SENTRY persona and sequential multi-action execution contract.
- Preserve Vosk -> Whisper -> one Codex turn -> Kokoro.
- Configure a British male Kokoro voice across conversational, proactive,
  reminder, and alarm speech.
- Add a bounded local-artifact display tool.
- Add durable, restart-safe, one-shot local alarms with typed API/MCP tools and
  a lightweight user-systemd timer.
- Keep office vision available as an explicit on-demand MCP tool; do not upload
  frames or weaken enrolled-profile identity truth.
- Keep the voice/state API/alarm runtime independently controllable from
  continuous perception.

## Boundaries

- SENTRY is the visible persona; Codex is an implementation detail unless the
  operator asks about it.
- No second agent or deterministic natural-language intent router.
- No cloud audio/video, biometric inference by appearance, transcript archive,
  or hidden filesystem/network claim.
- Looking up availability may be autonomous; booking, payment, sending, or
  another consequential external commitment still requires an explicit user
  instruction and truthful confirmation of the actual outcome.
- Alarms are one-shot only in this slice: no recurrence, snooze, timers, or
  calendar scheduler.

## Acceptance

- `Sentry` wakes the accepted listener and arbitrary natural requests reach the
  direct Codex agent.
- A representative five-part request is executed and reported in order.
- Native web, image creation/display, local file action, weather, and alarm
  creation paths are available to the same turn.
- All normal SENTRY speech uses Kokoro `bm_george` and local PipeWire playback.
- One-shot alarms are durable, idempotent, claim-before-speech, restart-safe,
  listable, cancellable, and delivered without Luna.
- Focused and full regression pass; privacy and process state are truthful.
